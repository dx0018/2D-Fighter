# Shared interface

Config exports `characters` (array) and `maps` (array) in src/config/content.js.
Character: id (doraemon/po), name (Chinese), englishName, tagline, description, color (hex string), stats {power,speed,range} 1..5, maxHp,maxEnergy,speed,jump, moves {attack,skill,ultimate}. Each move {name,damage,range,cooldown,cost,windup,active,recovery,kind,color,...}.
Map: id,name,englishName,description,tag,theme (town/sunset/moon), colors {sky,ground,accent}, bounds {left,right}, spawns [{x,facing},{x,facing}], camera {minWidth,maxWidth,left,right}, objects [{id,type:crate/sign,x,hp,width,...}]. Floor y=0; world x in roughly -32..32; visual fighter height around 3.0–3.3; combat hitbox height 2.6.
Engine exports Game from src/game/engine.js. new Game({characters:[character,character],map,onEvent}) .step(dt, inputs) where inputs array of {left,right,jump,crouch,attack,skill,ultimate}, booleans; edge detection internal. .state is {fighters,objects,projectiles,effects,time,phase,countdown,winner,shake,hitstop,impactPulse}. phase countdown/fighting/finished. .paused boolean set by UI. fighters {id,character,x,y,vx,vy,facing,hp,energy,cooldowns:{attack,skill,ultimate},action,actionTime,stun,flash,crouching, grounded}. action idle/walk/jump/crouch/attack/skill/ultimate/hurt/victory/defeat. Objects mutable config+{hp,destroyed,shake,flash}. projectiles {x,y,direction,owner,color,radius,...}; effects {type,x,y,color,life,maxLife,...}. time seconds remaining. winner 0/1/'draw'/null. Countdown 3->0 seconds. onEvent({type, ...}) for hit/cast/release/break/end/countdown. .reset(). Inputs ignored during paused/countdown/finished. Game logic is DOM independent.
Renderer exports ArenaRenderer from src/render/arena.js. new ArenaRenderer(container,{map,characters:[...],onError}) supports .update(state,dt), .resize(), .dispose(). Uses Three.js; creates canvas; graceful canvas fallback on WebGL failure. .update can accept engine state. Also export createPortrait(character) returning a WebP image with SVG fallback markup for config-driven cards, no remote resources (may implement in separate portraits.js exported there). UI uses portraits from src/render/portraits.js. Root handles UI, HUD, input binding, sound.

Move impact {stop,shake} drives hitstop and camera response. Fighters also expose bufferedMove, jumpBuffer, combo, comboDamage, comboWindow, hitDirection. Input buffers are 120ms and do not accept moves with insufficient energy or long remaining cooldown. Effects have stable IDs and castId for canceling interrupted charge visuals. ArenaRenderer uses a PerspectiveCamera and reads actual currentMove.elapsed to pose its rigs. Pass dt=0 while paused. Render modules are split into fighters, animation, stages, camera, effects, primitives, and fallback.
