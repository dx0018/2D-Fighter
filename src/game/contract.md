# Shared interface

Config exports `characters` (array) and `maps` (array) in src/config/content.js.
Character: id (doraemon/po/naruto), name (Chinese), englishName, tagline, description, color (hex string), stats {power,speed,range} 1..5, maxHp,maxEnergy,speed,jump, moves {attack,skill,ultimate}. Each move {name,damage,range,cooldown,cost,windup,active,recovery,kind,color,...}.
Map: id,name,englishName,description,tag,theme (town/sunset/moon), colors {sky,ground,accent}, bounds {left,right}, spawns [{x,facing},{x,facing}], camera {minWidth,maxWidth,left,right}, objects [{id,type:crate/sign,x,hp,width,...}]. Floor y=0; world x in roughly -32..32; visual fighter height around 3.0–3.3; combat hitbox height 2.6.
Engine exports Game from src/game/engine.js. new Game({characters:[character,character],map,onEvent}) .step(dt, inputs) where inputs array of {left,right,jump,crouch,attack,skill,ultimate}, booleans; edge detection internal. .state is {fighters,objects,projectiles,effects,time,phase,countdown,winner,shake,hitstop,impactPulse}. phase countdown/fighting/finished. .paused boolean set by UI. fighters {id,character,x,y,vx,vy,facing,hp,energy,cooldowns:{attack,skill,ultimate},action,actionTime,stun,flash,crouching, grounded}. action idle/walk/jump/crouch/attack/skill/ultimate/hurt/victory/defeat. Objects mutable config+{hp,destroyed,shake,flash}. projectiles {x,y,direction,owner,color,radius,...}; effects {type,x,y,color,life,maxLife,...}. time seconds remaining. winner 0/1/'draw'/null. Countdown 3->0 seconds. onEvent({type, ...}) for hit/cast/release/break/end/countdown. .reset(). Inputs ignored during paused/countdown/finished. Game logic is DOM independent.
Renderer exports ArenaRenderer from src/render/arena.js. new ArenaRenderer(container,{map,characters:[...],onError}) supports .update(state,dt), .resize(), .dispose(). Uses Three.js; creates canvas; graceful canvas fallback on WebGL failure. .update can accept engine state. Also export createPortrait(character) returning a WebP image with SVG fallback markup for config-driven cards, no remote resources (may implement in separate portraits.js exported there). UI uses portraits from src/render/portraits.js. Root handles UI, HUD, input binding, sound.

Move impact {stop,shake} drives hitstop and camera response. Fighters also expose bufferedMove, jumpBuffer, combo, comboDamage, comboWindow, hitDirection. Move inputBuffer config defaults to 120ms; both normal attacks use 180ms. Buffered moves do not accept insufficient energy or long remaining cooldown, and still wait for recovery and cooldown. Expiration is checked at the start of a simulation tick so presses on the exact cooldown boundary survive fractional tick rounding. Effects have stable IDs and castId for canceling interrupted charge visuals. ArenaRenderer uses a PerspectiveCamera and reads actual currentMove.elapsed to pose its rigs. Pass dt=0 while paused.

Directional moves: base move.variants {forward,backward,crouch,air} inherit base fields. moves.js exports moveContext, selectMove and moveList; precedence air > crouch > relative horizontal direction > neutral. Buffered taps capture context and facing. Variants share input-slot cooldowns; cooldownTotals stores the active total for the HUD. currentMove includes context and an optional committed ray {x,y,dx,dy}. Config animation selects the pose; posture=crouch retains the low hurtbox. Optional hitY/hitHeight, height/angle/beamRadius, movement, evade, gravityScale describe gameplay independently of rendering. Swept segment/AABB collision handles diagonal beams and projectiles. Crouch height is 2.3 and standing height is 2.6 world units. Projectile originX is configurable; a projectile crossing an invulnerable fighter is consumed as a successful dodge.

Locomotion exposes walkDistance, moveDirection, inputContext, jumpStartup (25ms), landingTimer/landingImpact. Ground movement reaches the requested velocity in the next simulation tick; air movement retains controlled easing. frameDelta accepts up to 100ms so 15–30fps does not introduce artificial slow motion. Walk distance tracks actual travel. rig.js creates fixed-length upper/lower Bone chains and a shared SkinnedMesh, with analytic two-bone IK and reachable targets. Torso pivots at the pelvis; head and body scale remain 1. Support feet retain world anchors, including during reversal. Air casts cancel on landing; charge effects follow cast progress during hitstop.

Combat rendering, keyboard sampling and simulation follow every browser animation frame; HUD text is paced separately at 30Hz with immediate phase transitions. Do not insert a fixed 60Hz drawing skip onto 90/144Hz displays. Doraemon's projectile height matches the hand-cannon muzzle, and the diving shot keeps its downward aim facing either direction.

Character locomotion {stride,lift,armSwing} controls signed, distance-driven gait. Reversing velocity reverses gait phase; walk blending and free-foot placement do not delay physics. Stance and swing trajectories have matching horizontal speed and zero vertical speed at contact. Leg IK limits horizontal reach at the desired floor height. Normal attack motion {prepare,reach} configures a continuous preparation, extension and recovery envelope; the fist reaches full extension at move.windup and returns to guard at recovery end. Helpers live in render/locomotion.js and render/melee-motion.js.

ArenaRenderer accepts quality ('auto'/'high'/'performance'), exposes setQuality, sampleFrame and needsRender. Auto responds to sustained frames below roughly 52fps. Static scenery shadows are captured before fighters/interactive objects are added; material shader hooks compose vertex-surface batching with cached shadow projection. Rigid head/body decorations are batched independently of animated facial parts. Expired combat effects retain buffers and materials in a pool bounded to 24 entries, keyed by type, color and hit weight; dispose releases both active and cached resources. UI pauses drawing while the game is paused and redraws immediately after resize or quality changes.

Normal attacks optionally set recoveryMovement (fraction of recovery elapsed, currently .55). recoveryMovement(cast) in moves.js gates standing ground movement during late recovery; the cast, hit set and cooldown remain intact. walkDistance includes this travel, so the gait blends back before the punch finishes. Basic attack hitstop is 28/34ms and cooldown is .42/.52s. Free feet smooth in world space, with a toe-off offset from the actual support anchor; air ankles inherit root travel.

src/i18n/index.js exports getLanguage, setLanguage, translate and localize. The en.js dictionary translates Chinese source copy, including configuration data. localize stores original text/attributes in WeakMaps and preserves DOM/canvas/game instances. Dynamic HUD text uses translate before updates. Local storage pocket-language persists zh/en; document language/title/description follow the choice.

Naruto lives in config/naruto.js, imported by the roster. The Game constructor still takes exactly two selected fighters, independently of roster size. ninja bodyStyle uses the shared fighter-rig.js builders and fixed bones with a slimmer head/torso. naruto-animation.js poses Rasengan and Bijuu charge/release; ninja-effects.js creates lightweight rotating chakra orbs and kunai. move.visual (rasengan/bijuu/kunai) selects rendering and audio, independent of move.kind collision. diveSpeed applies only during an airborne dash active window; landing still cancels the air cast. substitution spawns a noncolliding log/smoke effect alongside the configured evasion and kunai projectile. Ordinary Rasengan is a short dash strike; Tailed Beast Bomb is one cost-gated, interruptible projectile. Effects validate pooled signatures if reset reuses an ID. Both model previews and Canvas fallback have a Naruto appearance.
