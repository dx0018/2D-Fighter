# Shared interface

Config exports `characters` (array) and `maps` (array) in src/config/content.js.
Character: id (doraemon/po), name (Chinese), englishName, tagline, description, color (hex string), stats {power,speed,range} 1..5, maxHp,maxEnergy,speed,jump, moves {attack,skill,ultimate}. Each move {name,damage,range,cooldown,cost,windup,active,recovery,kind,color,...}.
Map: id,name,englishName,description,tag,theme (town/sunset/moon), colors {sky,ground,accent}, bounds {left,right}, spawns [{x,facing},{x,facing}], camera {minWidth,maxWidth,left,right}, objects [{id,type:crate/sign,x,hp,width,...}]. Floor y=0; world x in roughly -17..17; fighter height 2.6.
Engine exports Game from src/game/engine.js. new Game({characters:[character,character],map,onEvent}) .step(dt, inputs) where inputs array of {left,right,jump,crouch,attack,skill,ultimate}, booleans; edge detection internal. .state is {fighters,objects,projectiles,effects,time,phase,countdown,winner,shake}. phase countdown/fighting/finished. .paused boolean set by UI. fighters {id,character,x,y,vx,vy,facing,hp,energy,cooldowns:{attack,skill,ultimate},action,actionTime,stun,flash,crouching, grounded}. action idle/walk/jump/crouch/attack/skill/ultimate/hurt/victory/defeat. Objects mutable config+{hp,destroyed,shake,flash}. projectiles {x,y,direction,owner,color,radius,...}; effects {type,x,y,color,life,maxLife,...}. time seconds remaining. winner 0/1/'draw'/null. Countdown 3->0 seconds. onEvent({type, ...}) for hit/cast/break/end/countdown. .reset(). Inputs ignored during paused/countdown/finished. Game logic is DOM independent.
Renderer exports ArenaRenderer from src/render/arena.js. new ArenaRenderer(container,{map,characters:[...],onError}) supports .update(state,dt), .resize(), .dispose(). Uses Three.js; creates canvas; graceful canvas fallback on WebGL failure. .update can accept engine state. Also export createPortrait(character) returning SVG markup for config-driven cards, no remote resources (may implement in separate portraits.js exported there). UI uses portraits from src/render/portraits.js. Root handles UI, HUD, input binding, sound.
