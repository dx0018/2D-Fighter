# 对战体验检查

## 本轮已处理

- 旧腿部主要沿纵深摆动，步态与横向位移脱节。现在用实际移动距离推进支撑与摆腿，加入屈膝、抬脚、反向摆臂和加减速，减少滑步。
- 旧蹲姿仅压缩模型。现在分离腿部与上身，降低髋部、屈膝，保持脚底接触和脸部比例。蹲姿技能持续使用低位判定。
- 跳跃缺少重量。现在有短暂蹬地、空中收腿、下降和落地缓冲；跳跃＋技能同按会进入空中招式，落地取消未完成的空中招式。
- 技能选择少。两名角色均有原地、向前、后退、下蹲、空中技能，普攻另有扫腿和飞踢。高低位、空对空、突进和后撤有不同用途，共享冷却避免切方向绕过限制。
- 新招式需要引导。HUD 随姿态显示招式，对战页及帮助有配置生成的招式表。方向相对敌人，换边后仍按相同语义操作。
- 斜向射线与炮弹使用同一方向绘制和判定，快速投射物使用连续判定。蓄力被打断后不继续放招或播放释放音效。

## 后续优先级

1. **防御博弈**：已加入后退格挡、上下段应对、能量消耗与崩解。下一步可考虑投技，避免近身一直防守；需先试玩验证削血与能量消耗是否合理。
2. **可确认的连段**：已加入命中确认取消。普攻命中后可在配置窗口内接技能或大招，技能命中可接大招；格挡与落空保留完整收招。确认大招会消耗原有 70 EP 并延长对手硬直至释放。下一步需要真人试玩，检查不同角色招式距离、窗口和大招硬直的平衡。
3. **训练与反馈**：加入训练假人、输入历史、判定显示和一键复位，让玩家能练距离，也便于准确调参。
4. **局间节奏与平衡**：已加入三局两胜、局间恢复与比分显示。下一步通过真人双人试玩确认远程牵制、冲撞落空和后退技能的强弱，再调整能量、冷却与局间恢复。

后续一轮已改为骨骼蒙皮、固定肢长 IK 与刚性躯干转动，补了反向移动的脚掌锁定、画质控制与渲染优化。细节见 [建模、动作与性能](model-motion-performance.md)。手工关键姿势仍可继续完善；自动检查验证输入、判定与流程，胜率和手感仍需双人试玩。

## 地图与目标更新

原有地图虽约 60 米宽，但只有 3 件互动道具，走远没有收益。现在扩大到 74／80／76 米，中央与侧翼设能量补给、木箱有有限能量奖励，电脑会争夺资源。地图复杂度先来自位置和刷新时机；暂不增加高台与纵深移动，避免破坏已有横向招式判定。

下一步优先验证真人对局中是否出现过度逃跑或资源滚雪球，再考虑有明确预警的场景机关、不同 CPU 难度和训练模式。自动检查能发现规则问题，竞技平衡仍需真人试玩。

## 命中确认与连段

连续命中计数现在与实际取消衔接相连。角色招式配置可为普通攻击设置 `cancelOnHit: ["skill", "ultimate"]`，技能可设置 `cancelOnHit: ["ultimate"]`，并用 `cancelWindow` 控制反应时间。只有受击目标被有效命中、攻击方仍在原招式中时才开放窗口；普通防守、落空、打木箱、被打断或原招式收招结束都不能提前取消。HUD 会显示确认窗口和可衔接招式。电脑会在确认窗口内选择可用的技能或大招。

在确认窗口内接大招时，目标硬直会延长至大招释放和有效段结束。大招仍消耗 70 EP 并保留冷却；这条高代价路线能形成清楚的收尾。对战平衡仍需要真人检查，尤其关注大招命中后的伤害交换。


## 三局两胜

网页通过 roundsToWin: 2 开启三局两胜；引擎默认 roundsToWin: 1，维持单局使用方式。平局不计分；每局间显示小比分，短暂停顿后重新初始化角色、场景互动对象和补给，但保留系列赛比分。先赢两局立即获胜；三局后比分打平则整场平局。最终结算显示系列赛比分，暂停重开从第一局开始并清空分数。
